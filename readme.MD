## 🌟 Key Features

### ⚡ 1. Real-Time Chat & Socket.IO Instant Messaging
- **1-on-1 Direct Messaging**: Low-latency, bidirectional real-time chat powered by Socket.IO WebSockets.
- **Rich Media Transmission**: Send photos and videos smoothly along with text messages using Cloudinary CDN media URLs.
- **Message Read Receipts**: Live double-tick status indicators (`sent` ➔ `delivered` ➔ `read`) updated in real-time.
- **Interactive Emoji Reactions**: Tap to attach emoji reactions (`❤️ 👍 😂 😮 😢 🔥`) to individual messages with instant WebSocket broadcast updates.

### 📸 2. 24-Hour Status Stories & Viewer Tracking
- **Ephemeral Status Updates**: Post text, photo, or video status stories that automatically expire after 24 hours (MongoDB TTL index `86400s`).
- **Viewer Tracking List**: Track who viewed your status updates in real-time with full user profiles.
- **Grouped User Status Feed**: Chronologically organized status stories grouped by contact profile.

### 🔒 3. Dual-Channel Authentication (Email & SMS OTP)
- **Multi-Factor OTP Login**: Seamless authentication via 6-digit OTP sent over Email (Nodemailer) or SMS Phone Number (Twilio service integration with DB fallback).
- **Secure JWT Auth**: Secure HTTP-only cookies (`auth_token`) with 1-year persistent session expiration.
- **Profile Customization**: Customizable username, profile avatar upload via Cloudinary, and "Hey there! I am using WhatsApp." bio/about string.

### 🔔 4. Real-Time Online Presence & Typing Indicators
- **User Online/Offline Status**: Automatic presence detection (`userConnected`, `disconnect`, `userStatusChanged`) with `lastSeen` timestamp logging.
- **Dynamic Typing Indicator**: Real-time "typing..." notification broadcasted when typing starts, featuring an automated 3-second inactivity auto-stop timer.

### 💬 5. Comprehensive Chat & Message Management
- **Edit & Delete Messages**: Edit existing message content or delete messages for all participants.
- **Conversation Cleanup**: Delete full conversation threads along with all historical messages in one action.
- **Unread Counter**: Dynamic conversation unread message counter that updates automatically when new messages arrive.

## ⚡ Quick Start Guide

### 1. Prerequisites
- **Node.js**: v18.x or higher
- **npm**: v9.x or higher
- **MongoDB**: Active MongoDB Atlas URI
- **Cloudinary Account**: Cloud name, API key & API secret
- **Email Service (Nodemailer)**: Gmail App Password / SMTP credentials

---

### 2. Clone & Install Dependencies

```bash
# Clone the repository
git clone https://github.com/nikhilxagr/whatsapp-fullstack-clone.git
cd whatsapp-fullstack-clone

# Install Backend dependencies
cd backend
npm install

# Install Frontend dependencies
cd ../frontend
npm install
```

---

### 3. Configure Environment Variables

Create a `.env` file in the `backend/` directory:

```env
PORT=8000
MONGO_URI=your_mongodb_atlas_connection_string
JWT_SECRET=your_jwt_secret_key
CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_email_app_password
FRONTEND_URL=http://localhost:3000
```

Create a `.env` file in the `frontend/` directory:

```env
REACT_APP_BACKEND_URL=http://localhost:8000
```

---

### 4. Run Locally

**Start Backend (Port 8000):**
```bash
cd backend
npm run dev
```

**Start Frontend (Port 3000):**
```bash
cd frontend
npm start
```

Visit **`http://localhost:3000`** in your browser!

## 🌐 API Reference

### Auth & User Endpoints (`/api/auth`)
| Method | Endpoint | Access | Description |
|---|---|---|---|
| `POST` | `/api/auth/send-otp` | Public | Send 6-digit OTP via Email or Phone SMS |
| `POST` | `/api/auth/verify-otp` | Public | Verify OTP & set secure HTTP-Only JWT Cookie |
| `PUT` | `/api/auth/update-profile` | Private | Update username, bio, and profile picture (Cloudinary) |
| `POST` | `/api/auth/logout` | Private | Clear JWT cookie & log out user |
| `GET` | `/api/auth/check-auth` | Private | Check current user authentication status |
| `GET` | `/api/auth/users` | Private | Fetch all users with last message conversation data |

### Chat & Message Endpoints (`/api/chat`)
| Method | Endpoint | Access | Description |
|---|---|---|---|
| `POST` | `/api/chat/send-message` | Private | Send text, photo, or video message with Socket.IO alert |
| `GET` | `/api/chat/conversations` | Private | Fetch all active user conversations sorted by latest activity |
| `GET` | `/api/chat/messages/:conversationId` | Private | Fetch conversation message history & auto-mark sent as read |
| `PUT` | `/api/chat/mark-as-read` | Private | Mark specific message status as `read` |
| `PUT` | `/api/chat/message/:messageId` | Private | Edit message content or replace media attachment |
| `DELETE` | `/api/chat/message/:messageId` | Private | Delete individual message |
| `DELETE` | `/api/chat/conversation/:conversationId` | Private | Delete full conversation thread & all messages |

### Status / Story Endpoints (`/api/status`)
| Method | Endpoint | Access | Description |
|---|---|---|---|
| `POST` | `/api/status/create` | Private | Create text, photo, or video status story (24h TTL) |
| `GET` | `/api/status/all` | Private | Fetch active status stories from all users within last 24h |
| `GET` | `/api/status/my-status` | Private | Fetch logged-in user's active statuses with viewers list |
| `PUT` | `/api/status/view/:statusId` | Private | Record user view on a status story |
| `DELETE` | `/api/status/delete/:statusId` | Private | Delete user's active status story |
